ESS-DIVE · 2026

Denudation, solute export, landscape evolution modeling, and geographic information system data for the East River watershed, Colorado, USA (2020–2024)

Measurements and model outputs for examining how bedrock properties influence erosion, solute export, and landscape adjustment in the East River watershed.

Open data record

What the dataset covers

  • Denudation measurements
  • Solute export data
  • Landscape evolution modeling
  • Geographic information system data

Using the data

Measurements and model outputs cover 2020–2024. File descriptions, methods, and reuse information are available in ESS-DIVE.
